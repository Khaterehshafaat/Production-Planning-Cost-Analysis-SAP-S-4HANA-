# SAP S/4HANA Production Planning – Global Bike Case Study

End-to-end SAP S/4HANA Production Planning and Execution project
using the Global Bike dataset.

## Overview

This project demonstrates a complete manufacturing planning and
execution workflow in SAP S/4HANA 2022, including demand planning,
MRP, production execution, inventory movements, and production cost
settlement.

## Key Processes

- Material Master & Routing
- Sales & Operations Planning (SOP)
- Demand Management
- Master Production Scheduling (MPS)
- Material Requirements Planning (MRP)
- Production Order Management
- Goods Receipt & Goods Issue
- Production Confirmation
- Production Cost Analysis
- Cost Settlement

## Tools

- SAP S/4HANA 2022
- SAP Fiori 3.0
- Global Bike Dataset
- Production Planning (PP)
- Materials Management (MM)
- Controlling (CO)

## Project Workflow

Material Master
→ Routing
→ SOP
→ Demand Management
→ MRP
→ Production Order
→ Goods Issue
→ Production Confirmation
→ Goods Receipt
→ Cost Analysis
→ Settlement
